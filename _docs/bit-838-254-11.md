## Notes

**Functionally identical to [[bit-838-254-19-7314|H02]].** Same radius, same 1" OD, same bearing size and position, same shank. The only real difference is that this part number resolves cleanly against CMT's published catalog, where H02's `.19` suffix doesn't. Worth keeping both cataloged separately since they're two physical bits, not one — a second one in the drawer means a spare when the first one's edge finally goes.

**Bearing rides below the cut**, same as H02: the arc rounds the top corner, the bearing follows the vertical face underneath it.
