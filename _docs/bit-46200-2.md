A second [[bit-46200|D03]], not a new geometry. Same part number, same physical bit, kept as a spare for whenever the first one dulls or breaks mid-job.

## Specifications

Identical to [[bit-46200|D03]] — 1/8" cutting diameter, 1/4" reduced shank, 1/2" LOC, 2" OAL, 2-flute down cut spiral. See that note for the full spec table and feeds and speeds; there's no reason to retype numbers that are true of both bits by definition.

## Notes

**Shares D03's Fusion tool entry (T12) rather than getting its own T-number.** Fusion's tool library dedupes on `product-id`, and a CAM program cares about the cutting profile, not which physical stick of carbide is chucked in the collet — a second identical bit doesn't need a second toolpath definition, just a second bit in the drawer. This note exists so the vault's inventory (what's actually on hand, sharpied and ready) doesn't undercount what the Fusion library alone would suggest.

**Swap it in when D03 dulls or snaps.** Same T12 offsets apply; no program needs to change, just the physical tool in the spindle.
