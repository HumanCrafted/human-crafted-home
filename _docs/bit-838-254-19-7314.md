The second bit in the H series, and the first roundover for the hand router. Quarter-round profile: a 1/4" radius cut into a 1" diameter cutter, bearing riding below the arc so the flutes only touch what's above the bearing's contact line.

## Notes

**Part number reads 838.254.19-7314, not the more commonly listed 838.254.11.** Every CMT roundover bit indexed online in this radius (1/4" radius, 1" OD, 1/2" cutting length, 1/4" shank) carries the `.11` suffix — nothing turned up for `.19`, and `-7314` looks like a separate batch or date code stamped alongside the part number rather than part of it. Radius and bearing diameter confirmed directly off the bit match the `.254` family exactly, so the spec above is trustworthy even though the exact suffix isn't.

**Bearing rides below the cut, opposite of [[bit-2400|H01]].** A flush trim bit's bearing follows a template above the material it's cutting; a roundover's bearing follows the vertical face below the arc it's rounding over. Different job, so the bearing sits on the opposite end of the profile.

**No CNC crossover here.** [[bit-2052|R01]] is the CNC-side equivalent geometry, but it swaps the bearing for a solid ground pilot so the toolpath can do the guiding instead of a surface. This one only works by feel, off the router table or handheld.
