## Notes

**Still an upcut.** The coating changes tool life, not physics: it lifts fibres at the top face like any upcut, so show faces on veneered sheet still belong to [[bit-420-dnc250|D01]] or [[bit-46202-k|D02]].

**Plunge-ground, so straight plunges are fine** — that's the "spiral plunge" in Amana's name, and the plunge feeds above lean on it. Ramping is still gentler when the toolpath allows.

**1" of flute covers 3/4" through-cuts** with spoilboard offset to spare, so U01's extra quarter inch only matters past inch-thick stock.
