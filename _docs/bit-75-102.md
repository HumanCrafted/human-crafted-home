## Notes

**Tears the top face on plywood and veneer**, same upcut tradeoff as U01/U04. Reach for [[bit-420-dnc250|D01]] or [[bit-46202-k|D02]] instead whenever the top face shows.

**Plunges fine** — nothing in Freud's own spec calls this out as plunge-ground the way Amana marks its "spiral plunge" line, but it's a standard upcut with the same chip-evacuation behavior as U01/U04, so the same practice applies.

**Black I.C.E. does its real work in MDF and laminate**, same logic as Spektra on U04 — the coating buys life against abrasive sheet goods more than it does in solid hardwood.
