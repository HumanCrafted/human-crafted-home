A 1/4" roundover that runs in the CNC, not a hand router. No bearing: the pilot is a ground nose on the bit itself (Whiteside calls it a plunge point), which is what makes it CNC-usable at all — nothing to ride, so the toolpath does the guiding and it can even plunge.

## Feeds & Speeds

For the X-Carve Pro and its 1.5 kW spindle. These match the presets stored on this tool in the Fusion hub library. Chipload is figured at the rim, the 3/4" top of the arc; engagement on an edge pass is a light quarter-round sliver, so one pass at full profile is the normal cut.

Same logic as [[bit-45704|V01]]: profiling cuts with light engagement run higher RPM than the chipload method would normally allow, and the programmed feed is a ceiling the machine rarely reaches on a contour full of corners.

## Notes

**Run it as a 2D Contour along the top edge**, depth set so the arc lands tangent to the top face. In the library it's typed as a radius mill, so Fusion models the full profile (1/4" pilot, 1/4" radius, 3/4" shoulder) and the toolpath comes out right without offset tricks.

**The pilot is solid, not a bearing.** On the CNC it mostly cuts air below the arc, but wherever it does touch, it touches at spindle speed. Don't let a toolpath park it against a finished face, and don't dwell in corners.

**Do this after the part is cut free or tabbed**, like any finishing pass. The side load is small, but a rounded edge is a visible edge; it deserves the same workholding care as a finish contour.
